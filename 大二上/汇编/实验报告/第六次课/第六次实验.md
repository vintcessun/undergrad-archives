## 1.实验目的

1. **掌握汇编语言中 DOS 系统功能调用（int 21h 等）的使用方法**，理解系统调用在字符输入、输出及串处理中的作用。
2. **熟悉并能够正确运用串操作指令**（如 `movsb、movsw、cmpsb、scasb` 等），实现对字符串的搜索、比较及替换操作。
3. **综合运用前几次实验中学习的汇编指令、循环结构、地址计算与 DEBUG 调试技巧**，完成对字符串的查找与替换等功能，实现小型字符串处理程序。

## 2.实验环境

- **操作系统：** Windows（Windows 11）
- **运行环境：** DOSBox 模拟器（模拟 x86 实模式）
- **实验与调试工具：**
  - DEBUG（DEBUG.exe，用于调试 16 位汇编 COM 程序）
  - 需要时可使用 MASM、LINK 编译汇编程序

## 3.实验内容

1. **从键盘输入两个字符串：**
   - A 串，例如 `"software"`
   - B 串，例如 `"school of software engineering"`
2. **判断 A 是否在 B 中存在。**
   - 若存在，输出 `"FOUND"`
   - 若不存在，输出 `"NOT FOUND"`
   - 需要使用串比较相关指令（如 `cmpsb` 或循环比较）
3. **实现字符串替换：**
   - 在确认 B 串中**存在** A 串的情况下，使用第三个字符串 C 去**替换 B 中第一次出现的 A**。
   - C 的长度可以与 A 不同，需要正确处理长度变化。
   - 替换后的 B 串需要在屏幕上显示出来。

## 4.实验具体实现

### 代码

```asm
data segment
    bufferA db 32
            db 0
            db 32 dup('$')
    db 4 dup(0)
    bufferB db 32
            db 0
            db 32 dup('$')
    db 4 dup(0)
    bufferC db 32
            db 0
            db 32 dup('$')
    db 4 dup(0)
    
    temptail db 80 dup(0)
    
    promptstringA db 'input a string:',0AH,0DH,'$'
    promptstringB db 'input b string:',0AH,0DH,'$'
    promptstringC db 'input c string:',0AH,0DH,'$'
    promptstringENTER db 0AH,0DH,'$'
    foundstring db 'found & replaced:',0AH,0DH,'$'
    notfoundstring db 'not found it',0AH,0DH,'$'
    
data ends

code segment
    assume cs:code,ds:data,es:data

start:
    mov dx,data
    mov ds,dx
    mov es,dx

    mov dx,offset promptstringA
    mov ah,09H
    int 21H

    mov dx,offset bufferA
    mov ah,0AH
    int 21H

    mov dx,offset promptstringENTER
    mov ah,09H
    int 21H

    mov dx,offset promptstringB
    mov ah,09H
    int 21H

    mov dx,offset bufferB
    mov ah,0AH
    int 21H

    mov dx,offset promptstringENTER
    mov ah,09H
    int 21H

    mov dx,offset promptstringC
    mov ah,09H
    int 21H

    mov dx,offset bufferC
    mov ah,0AH
    int 21H

    mov si,offset bufferC
    add si,2
    mov cl,[si-1]
    mov ch,0H
    add si,cx
    mov byte ptr [si],'$'

    mov dx,offset promptstringENTER
    mov ah,09H
    int 21H
    
    mov al,[bufferA+1]
    mov ah,00H
    mov cx,ax
    mov bp,cx

    mov bl,[bufferB+1]
    mov bh,00H
    mov bx,bx
    
    cmp bx,cx
    jb notfound
    sub bx,cx
    
    mov dx,00H

again:
    cmp dx,bx
    jg notfound

    mov si,offset bufferB+2
    add si,dx

    mov di,offset bufferA+2
    mov cx,bp

    cld
    push si
    push di
    push cx
    repe cmpsb

    pop cx
    pop di
    pop si

    jnz compare_fail
    
    jmp found

compare_fail:
    inc dx
    jmp again

found:
    mov di,offset temptail
    xor ax,ax
    mov cx,80H
    cld
    rep stosb
    
    mov di,offset temptail
    mov cx,dx
    cmp cx,0H
    je copy_c

    mov si,offset bufferB+2
    cld
    rep movsb

copy_c:
    mov cl,[bufferC+1]
    mov ch,0H
    cmp cx,0H
    je copy_suffix

    mov si,offset bufferC+2
    cld
    rep movsb

copy_suffix:
    mov ax,dx
    mov cl,[bufferA+1]
    mov ch,0H
    add ax,cx
    mov bp,ax
    
    mov cl,[bufferB+1]
    mov ch,0H
    sub cx,bp
    
    cmp cx,0H
    jle finish_replace

    mov si,offset bufferB+2
    add si,bp
    
    cld
    rep movsb

finish_replace:
    mov al,[bufferB+1]
    mov ah,0H
    mov cl,[bufferA+1]
    mov ch,0H
    sub ax,cx
    mov cl,[bufferC+1]
    mov ch,0H
    add ax,cx
    mov [bufferB+1],al

    mov cl,al
    mov ch,0H
    mov si,offset temptail
    mov di,offset bufferB+2
    cld
    rep movsb
    
    mov dx,offset foundstring
    mov ah,09H
    int 21H
    
    mov si,offset bufferB+2
    add si,ax
    mov byte ptr [si],'$'
    
    mov dx,offset bufferB+2
    mov ah,09H
    int 21H

    jmp endpro

notfound:
    mov dx,offset notfoundstring
    mov ah,09H
    int 21H

endpro:
    mov ax,4C00H
    int 21H

code ends
end start
```

## 5. 实验分析与总结

本次实验旨在掌握汇编语言中 **DOS 系统功能调用 (int 21h)** 的使用方法，特别是用于字符输入输出（如 `09H` 和 `0AH` 功能）的作用，并熟练运用 **串操作指令**（如 `cmpsb` 和 `movsb`）来实现字符串的查找和替换功能。

### 核心功能实现与分析

1. #### 字符串输入与显示:

   - 程序使用了 **09H 功能** 显示字符串，输出提示信息。
   - 使用了 **0AH 功能** 从键盘输入字符串，获取 A、B、C 三个字符串。该功能将输入的最大长度存放在缓冲区第一个字节，实际输入长度存放在第二个字节，字符串从第三个字节开始。
   - 在接收 C 串输入后，代码通过计算实际长度并在其末尾添加 `$` 终止符，使其可以直接使用 $09H 功能进行输出。

2. #### 字符串查找（A 串在 B 串中）:

   - 首先，程序计算了 A 串和 B 串的实际长度，并检查 B 串的长度是否大于 A 串的长度。
   - 查找使用了嵌套循环结构：
     - 外层循环（`again`）负责移动 B 串的起始比较位置。
     - 内层循环使用了 **`repe cmpsb`** 指令进行字符比较。在 CX 计数不为零且 ZF=1（字符相等）时重复比较 DS:SI 和 ES:DI 指向的字节。
     - 查找成功（ZF=1）则跳转到 `found`；失败则增加 DX（偏移量）并继续外层循环。

3. #### 字符串替换:

   - 替换的逻辑是：**前缀 → C 串 → 后缀**。
   - 替换时，先将 B 串中 A 串首次出现位置之前的部分（即前缀）复制到临时缓冲区 `temptail` 中，DX 寄存器保存了 A 串在 B 串中首次出现的起始偏移量。
   - 接着，将 C 串复制到 `temptail` 中前缀的末尾。
   - 然后，计算 B 串中 A 串之后的部分（即后缀）的起始位置和长度，并将其复制到 `temptail` 中 C 串的末尾。
   - 最后，更新 B 串的实际长度，并将 `temptail` 中的结果复制回 `bufferB` 中。

### 调试与优化

实验代码中正确地使用了 `cld` 清除方向标志位，确保 `cmpsb` 和 `movsb` 等串操作指令按地址递增方向进行。在查找比较时，为保护寄存器现场，正确地使用了 `push` 和 `pop` 操作。

本次实验的一个主要难点在于处理替换时 **字符串长度的变化**。由于 C 串和 A 串的长度可能不同，需要精确计算替换后 B 串的总长度，并在 `temptail` 缓冲区中进行拼接。代码中通过 AX 寄存器完成了这一复杂的长度计算，确保了替换后的 B 串能正确显示。

### 总结

通过本次实验，我不仅巩固了 **DOS 系统调用** 在控制台 I/O 中的应用，也深刻理解了 **`cmpsb`** 和 **`movsb`** 等串操作指令在汇编语言中处理字符串的效率和精确性。特别是字符串替换部分，要求对内存地址、长度计算以及 SI/DI 等寄存器的使用有精确的控制，极大地提升了我对汇编程序设计和底层数据操作的理解能力。
