## badcount.c

- __作用__: 演示printf函数参数数量错误

- __功能__: 展示三种常见的printf参数错误：参数过多、参数过少、参数类型不匹配

- __语义错误__:

  第9行：printf("%d\n", n, m); - 格式字符串只有1个%d，但提供了2个参数
  
  第10行：printf("%d %d %d\n", n); - 格式字符串有3个%d，但只提供了1个参数
  
  第11行：printf("%d %d\n", f, g); - 格式字符串需要整数，但提供了浮点数
