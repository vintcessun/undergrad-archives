# 2048

## 游戏简介
本项目是 2048 游戏的 C 语言命令行版本。  
保留了原有的游戏逻辑，实现了在命令行中进行游戏的功能。

## 编译方法
本项目提供 `makefile`，可直接使用 `make` 命令编译：
```bash
make
```
编译完成后会生成可执行文件 `2048`。

## 运行方法
```bash
./2048
```

## 操作说明
- **W**：上移
- **A**：左移
- **S**：下移
- **D**：右移

每次移动后会自动生成新的方块（2 或 4），当无法移动时游戏会自动重置。

## 文件说明
- `main.c`：游戏主程序，包含全部逻辑与命令行界面。
- `README.md`：说明文档。
- `makefile`：自动编译脚本。
