## 未收录的内容

本仓库并非完整镜像。原始文件夹共 **11,992 个文件 / 约 13.2 GB**，本仓库收录 **7,684 个文件 / 约 3.0 GB**，其余 **约 10.2 GB** 未上传，原因如下：

- **GitHub 单文件 100 MB 硬上限**：原始文件中有 22 个文件超过该限制（最大的是 1.8 GB 的计图大作业压缩包），无法直接入库。本仓库统一排除了超过 45 MB 的文件。
- **压缩包**（`.zip` `.rar` `.7z`，约 6.9 GB）：多为大作业与项目打包，体积占比最高。
- **视频**（`.mp4` 等，约 1.8 GB）：演示录屏、答辩视频。
- **编译产物与二进制**（`.exe` `.dll` `.lib` `.pdb` `.obj` `.class` `.jar` 等）：可由源码重新生成。
- **大体积数据文件**（`.dat` `.ppm` `.wav` `.idx` `.pack`）：如人脸关键点模型等。
- **构建目录**（`node_modules/` `__pycache__/` `Debug/` `Release/` `x64/` `.vs/` `.idea/` `.xmake/`）。

具体规则见根目录 [`.gitignore`](.gitignore)。被排除的文件仍保留在本地 OneDrive 中；如需其中某份大文件，可通过 GitHub Releases 单独发布（单个附件上限 2 GB）。
