## 2022-2023学年第一学期期末考试A卷 ##

一、（10分） 三阶矩阵$A$特征值为$1, -1, 2$，求矩阵$A^{*}+3A - 2E$行列式值。 

二、（10分） 已知二次型$f = x_{1}x_{2}+3x_{1}x_{3}-5x_{2}x_{3}$，求$x = Py$，把二次型化为规范形。 

三、（10分） 设$A=\begin{bmatrix}-1&1&0\\-2&2&0\\4&-2&1\end{bmatrix}$，求$A^{100}$。

四、（10分） 求一个与 $\alpha_{1} = [1, 1, -1, 1]^{T}$，$\alpha_{2} = [1, -1, 1, 1]^{T}$，$\alpha_{3} = [1, 1, 1, 1]^{T}$都正交单位向量。

五、（10分） 已知$A=\begin{bmatrix}0&3&3\\1&1&0\\-1&2&3\end{bmatrix}$，若$X = 2X + A$，求$X$。

六、（15分） 设$x_{1},x_{2},x_{3}$是$Ax = \beta$三个解，若$x_{1}+ x_{2}=[4, 6, -8, 4]^{T}$，$x_{3}=[1, 2, -1, -1]^{T}$，$R(A)=2$并且$[0, 1, -3, 0]^{T}$是$Ax = 0$的解，求方程组通解。

七、（15分） 设$\mathbb{R}^{3}$两个基为 $\alpha_{1}=\begin{bmatrix} 1\\ 0\\ 0 \end{bmatrix}$, $\alpha_{2}=\begin{bmatrix} 1\\ 1\\ 0 \end{bmatrix}$, $\alpha_{3}=\begin{bmatrix} 1\\ 1\\ 1 \end{bmatrix}$, $\beta_{1}=\begin{bmatrix} 1\\ 0\\ 0 \end{bmatrix}$, $\beta_{2}=\begin{bmatrix} 1\\ 1\\ 0 \end{bmatrix}$, $\beta_{3}=\begin{bmatrix} 1\\ 1\\ 1 \end{bmatrix}$ 求由$\alpha_{1},\alpha_{2},\alpha_{3}$到$\beta_{1},\beta_{2},\beta_{3}$过渡矩阵以及$\eta = [1,3,6]^{T}$在这两组基下的坐标。

八、（15分） $\begin{cases}x_{1}+2x_{2}+3x_{3}=0\\2x_{1}+3x_{2}+x_{3}=0\\3x_{1}+x_{2}+2x_{3}=0\end{cases}$和$\begin{cases}x_{1}+bx_{2}+(c-1)x_{3}=0\\2x_{1}+b^{2}x_{2}+cx_{3}=0\end{cases}$是同解线性方程组，求$a,b,c$的值。

九、（10分） 对任意$n$阶实矩阵$A$定义实函数$\vert\vert A\vert\vert={tr(A^{T}A)}$，证明若：$\vert\vert A\vert\vert<1$则$E-A$必可逆
