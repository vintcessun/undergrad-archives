| 题号 | $f(n)$ | $g(n)$ | 关系 | 说明 |
|------|--------|--------|------|------|
| (1) | $50$ | $3n$ | $f(n) = O(g(n))$ | 常数被线性函数上界控制 |

### 详细分析：

**(1) $f(n)=50,\ g(n)=3n$**

- $50 \leq c \cdot 3n$ 对足够大的 $n$ 成立（取 $c=1$，当 $n \geq 17$ 时）
- **$f(n) = O(g(n))$** ✓
- 不是 $\Omega$（$50$ 无法下界控制 $3n$），也不是 $\Theta$

---

**(2) $f(n)=6n+10\lfloor\log n\rfloor,\ g(n)=2\sqrt{n}$**

- $f(n) = \Theta(n)$（主导项是 $6n$）
- $g(n) = \Theta(\sqrt{n}) = \Theta(n^{0.5})$
- 线性 $n$ 严格快于 $\sqrt{n}$，即 $n = \omega(\sqrt{n})$
- **$f(n) = \Omega(g(n))$** ✓，实际上 $f(n) = \omega(g(n))$
- 不是 $O$（$n$ 不是 $O(\sqrt{n})$），也不是 $\Theta$

---

**(3) $f(n)=n/\log n - 1,\ g(n)=\log_3 n$**

- $f(n) = \Theta(n/\log n)$
- 比较 $n/\log n$ 与 $\log n$：
  - $\frac{n/\log n}{\log n} = \frac{n}{(\log n)^2} \to \infty$（当 $n \to \infty$）
- 所以 $n/\log n$ 严格快于 $\log n$
- **$f(n) = \Omega(g(n))$** ✓，实际上 $f(n) = \omega(g(n))$
- 不是 $O$，也不是 $\Theta$

---

**(4) $f(n)=n^2,\ g(n)=3^n$**

- 指数函数 $3^n$ 严格快于任何多项式函数
- $n^2 \leq c \cdot 3^n$ 对足够大的 $n$ 成立
- **$f(n) = O(g(n))$** ✓
- 不是 $\Omega$（$n^2$ 无法下界控制 $3^n$），也不是 $\Theta$

---

```c
Hanoi(n,a,b,c)
  if (n==1) move(a,c);
  else {
    Hanoi(n-1, a, c, b);   // 1
    move(a, c);            // 2
    Hanoi(n-1, b, a, c);
```

- **1**：`Hanoi(n-1, a, c, b)` — 将 $n-1$ 个盘子从 $a$ 借助 $c$ 移到 $b$。

## 第 4 题（13 分）数列极差问题

### 关键性质分析

合并操作 $a \oplus b = ab+1$ **不满足结合律**。以三个数为例：

- $(a \oplus b) \oplus c = (ab+1)c+1 = abc + c + 1$
- $a \oplus (b \oplus c) = a(bc+1)+1 = abc + a + 1$

两式之差为 $c - a$。这说明：**越大的数越晚参与合并，最终结果越大；越大的数越早参与合并，最终结果越小**。

由此得到贪心策略：
- **求 max**：每次合并**当前最小的两个数**（小根堆），让大数尽量保留到最后。
- **求 min**：每次合并**当前最大的两个数**（大根堆），让大数尽早被合并掉。

### 算法伪代码

```python
def getMax(a[1..n]):
    建立小根堆 H，将所有 a[i] 放入 H
    while H.size > 1:
        x = H.popMin()      # 取出最小
        y = H.popMin()      # 取出次小
        H.push(x * y + 1)   # 合并后放回
    return H.top()

def getMin(a[1..n]):
    建立大根堆 H，将所有 a[i] 放入 H
    while H.size > 1:
        x = H.popMax()      # 取出最大
        y = H.popMax()      # 取出次大
        H.push(x * y + 1)   # 合并后放回
    return H.top()

def calculateRange(a[1..n]):
    maxVal = getMax(a)
    minVal = getMin(a)
    return maxVal - minVal
```

### 复杂度分析

每次堆操作 $O(\log n)$，共进行 $n-1$ 次合并，总时间复杂度为 **$O(n \log n)$**，空间复杂度 **$O(n)$**。

## 第 5 题（12 分）分治法求最大最小

### 算法设计思想

将数组从中间分成两半，分别递归求出左半和右半的最大值与最小值，然后合并（比较两个最大值取更大者，比较两个最小值取更小者）。  
- 当区间只剩 **1 个元素**时：$\max = \min =$ 该元素。  
- 当区间只剩 **2 个元素**时：直接比较 1 次得到 $\max$ 和 $\min$。

### 伪代码

```python
def MaxMin(A, low, high):
    # 只有一个元素
    if low == high:
        return (A[low], A[low])
    
    # 两个元素，直接比较
    if high == low + 1:
        if A[low] < A[high]:
            return (A[high], A[low])   # (max, min)
        else:
            return (A[low], A[high])
    
    mid = (low + high) // 2
    (max1, min1) = MaxMin(A, low, mid)      # 左半
    (max2, min2) = MaxMin(A, mid+1, high)   # 右半
    
    return (max(max1, max2), min(min1, min2))  # 合并
```

### 对 $A=(48,12,61,3,5,19,32,7)$ 的求解过程

```
[48,12,61,3,5,19,32,7]  (n=8)
├─ 左半 [48,12,61,3]
│   ├─ [48,12] → 比较得 (max=48, min=12)
│   ├─ [61,3]  → 比较得 (max=61, min=3)
│   └─ 合并 → (max(48,61)=61, min(12,3)=3)
│
└─ 右半 [5,19,32,7]
    ├─ [5,19]  → 比较得 (max=19, min=5)
    ├─ [32,7]  → 比较得 (max=32, min=7)
    └─ 合并 → (max(19,32)=32, min(5,7)=5)
    
最终合并 → (max(61,32)=61, min(3,5)=3)
```

**结果：最大值 = 61，最小值 = 3。**

### 复杂度分析

设 $T(n)$ 为比较次数：
- $n=2$ 时，$T(2)=1$；
- $n>2$ 时，$T(n)=2T(n/2)+2$（两次递归 + 两次合并比较）。

解得 $T(n) = \frac{3n}{2} - 2$。当 $n=8$ 时，共比较 **10 次**，优于朴素算法的 $2n-2=14$ 次。

## 第 6 题（10 分）拔河分组问题

**算法设计思想**  
设总人数为 $n$，总重量 $S=\sum w_i$，令 $k=\lfloor n/2\rfloor$。问题转化为：从 $n$ 人中恰好选 $k$ 人，使其总重量最接近 $S/2$。用布尔 DP 数组 `dp[j][s]` 记录“能否选出 $j$ 人使其总重量为 $s$”，按 01 背包方式倒序更新。

---

**C 风格伪代码**

```c
int minWeightDiff(int w[], int n) {
    int S = 0;
    for (int i = 0; i < n; i++) S += w[i];      // 计算总重量
    
    int k = n / 2;                              // 较小组人数
    
    // dp[j][s] == 1 表示：从已处理的人中选出 j 人，总重量恰好为 s
    bool dp[k + 1][S + 1];
    memset(dp, 0, sizeof(dp));
    dp[0][0] = 1;                               // 选 0 人，重量为 0
    
    for (int i = 0; i < n; i++) {
        int wi = w[i];
        for (int j = k; j >= 1; j--) {          // 倒序：已选人数
            for (int s = S; s >= wi; s--) {     // 倒序：总重量
                if (dp[j - 1][s - wi])
                    dp[j][s] = 1;
            }
        }
    }
    
    int best = 0;
    for (int s = 0; s <= S; s++) {              // 找最接近 S/2 的可行重量
        if (dp[k][s] && abs(s - S / 2) < abs(best - S / 2))
            best = s;
    }
    
    return abs(S - 2 * best);                   // 最小两组重量差
}
```

> **注**：若 $n$ 为奇数，两组人数分别为 $k$ 与 $k+1$。对 $k$ 做 DP 即可，因为选 $k$ 人的补集自动构成 $k+1$ 人组，对称等价。

---

**复杂度分析**

- **时间复杂度**：$O(n \cdot k \cdot S) = O(n^2 \cdot S)$，其中 $S$ 为总重量（伪多项式时间）。
- **空间复杂度**：$O(k \cdot S) = O(n \cdot S)$。
