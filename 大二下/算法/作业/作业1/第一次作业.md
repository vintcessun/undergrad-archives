## 1-2

![image-20260305150416537](./%E7%AC%AC%E4%B8%80%E6%AC%A1%E4%BD%9C%E4%B8%9A.assets/image-20260305150416537.png)

**第1-2题答案:**

在算法的时间复杂度分析中，$O(1)$ 与 $O(2)$ **没有本质区别**，它们都是**常数阶复杂度**。

原因如下：

1. **等价性**：根据大O阶的定义，大O符号表示的是函数增长率的上界。在分析时会忽略常数系数。因为 $2$ 是常数，所以 $O(2) = O(1 \times 2) = O(1)$。
2. **共同特征**：两者都表示算法的执行时间不随输入规模 $n$ 的增加而增长，即无论处理的数据量有多大，执行时间都是恒定的。

## 1-3

![image-20260305150847438](./%E7%AC%AC%E4%B8%80%E6%AC%A1%E4%BD%9C%E4%B8%9A.assets/image-20260305150847438.png)

**第1-3题答案:**

$4n^2$的渐进表达式为$O(n^2)$

$\log{n}$的渐进表达式为$O(\log{n})$

$3^n$的渐进表达式为$O(3^n)$

$20n$的渐进表达式为$O(n)$

$2$的渐进表达式为$O(1)$

$n^{\frac{2}{3}}$的渐进表达式为$O(n^{\frac{2}{3}})$

$n!$的渐进表达式为$O(n!)$

排序如下：

$2<\log{n}<n^{\frac{2}{3}}<20n<4n^2<3^n<n!$

$n!$应该排在最高位，因为根据斯特林公式$n! \approx \sqrt{2\pi n} (\frac{n}{e})^n$。当 $n$ 足够大时，底数 $n/e$ 会远大于 3，因此 $n!$ 会迅速超过 $3^n$。

![image-20260305152600420](./%E7%AC%AC%E4%B8%80%E6%AC%A1%E4%BD%9C%E4%B8%9A.assets/image-20260305152600420.png)

**第1-5题答案:**

**(1) 对于线性阶 $f(n) = n$**

$n' = 100 \times n$

在新机器上能解输入规模为 **$100n$** 的问题。

**(2) 对于平方阶 $f(n) = n^2$**

$(n')^2 = 100 \times n^2$

对两边开平方，得 $n' = \sqrt{100} \times n = 10n$

在新机器上能解输入规模为 **$10n$** 的问题。

**(3) 对于立方阶 $f(n) = n^3$**

$(n')^3 = 100 \times n^3$

对两边开立方，得 $n' = \sqrt[3]{100} \times n \approx 4.64n$

在新机器上能解输入规模约为 **$4.64n$** 的问题。

**(4) 对于阶乘阶 $f(n) = n!$**

阶乘增长极快。

对于阶乘级或指数级算法，硬件性能的提升对可处理规模的增加**极其有限**。

## 1-6

![image-20260305153124123](./%E7%AC%AC%E4%B8%80%E6%AC%A1%E4%BD%9C%E4%B8%9A.assets/image-20260305153124123.png)

**第1-6题答案:**

**(1) $f(n) = \log n^2$ ; $g(n) = \log n + 5$**

$f(n) = 2\log n$，而 $g(n) \approx \log n$。忽略常数系数和常数项后，两者都是 $\log n$。

$f(n) = \theta(g(n))$。

**(2) $f(n) = \log n^2$ ; $g(n) = \sqrt{n}$**

$f(n) = 2\log n$ 是对数阶，而 $g(n) = n^{1/2}$ 是幂函数阶。对数函数的增长速度永远慢于任何正幂函数。

$f(n) = O(g(n))$。

**(3) $f(n) = n$ ; $g(n) = \log^2 n$**

$f(n)$ 是线性阶，而 $g(n)$ 是多项式对数阶。线性增长快于对数增长。

$f(n) = \Omega(g(n))$。

**(4) $f(n) = n\log n + n$ ; $g(n) = \log n$**

$f(n)$ 的主要项是 $n\log n$，显然比单纯的 $\log n$ 增长得快得多。

$f(n) = \Omega(g(n))$。

**(5) $f(n) = 10$ ; $g(n) = \log 10$**

两者都是常数（$g(n)$ 约等于 $3.32$ 或 $1$ 或 $2.3$ 取决于底数，但都是常数）。常数之间互为同阶。

$f(n) = \theta(g(n))$。

**(6) $f(n) = \log^2 n$ ; $g(n) = \log n$**

$f(n) = (\log n) \times (\log n)$，比 $g(n)$ 多了一个增长因子。

$f(n) = \Omega(g(n))$。

**(7) $f(n) = 2^n$ ; $g(n) = 100n^2$**

$f(n)$ 是指数阶，而 $g(n)$ 是平方阶（幂函数）。指数阶的增长速度远超任何幂函数。

$f(n) = \Omega(g(n))$。

**(8) $f(n) = 2^n$ ; $g(n) = 3^n$**

两者虽然都是指数阶，但底数不同。由于 $2 < 3$，当 $n$ 增大时，$2^n$ 会被 $3^n$ 远远甩在后面。

$f(n) = O(g(n))$。

## 1-7

![image-20260305153447792](./%E7%AC%AC%E4%B8%80%E6%AC%A1%E4%BD%9C%E4%B8%9A.assets/image-20260305153447792.png)

**第1-7题答案:**

由斯特林公式可知这两个是同阶的$n! =O(\sqrt{2\pi n} \left( \frac{n}{e} \right)^n)$。

因此
$$
\lim_{n \to \infty} \frac{n!}{n^n}\\
=\lim_{n\to \infty}{\frac{\sqrt{2\pi n} \left( \frac{n}{e} \right)^n}{n^n}}\\
=\lim_{n\to \infty}{\frac{e^{\frac{1}{2}\log{n}}\frac{n^n}{e^n}}{n^n}}\\
=\lim_{n\to \infty}{e^{\frac{\frac{1}{2}\log{n}}{n}}}\\
=e^{\lim_{n\to \infty}{\frac{\frac{1}{2}\log{n}}{n}}}\\
=e^0\\
=1
$$
所以同阶

## 1-8

![image-20260305154328510](./%E7%AC%AC%E4%B8%80%E6%AC%A1%E4%BD%9C%E4%B8%9A.assets/image-20260305154328510.png)

**第1-8题答案:**

**下界：**

当初始值 $n$ 本身就是 2 的幂次（例如 $n = 2^k$）时，算法会不断执行 `n = n/2`，直到变为 1。这个过程需要 $\log_2 n$ 次操作。

因此，计算时间的下界为 **$\Omega(\log n)$**。

---

**上界：**

该算法属于 **3n+1 猜想**。由于目前数学上尚未证明该算法对所有 $n$ 都能停机，因此其计算时间的**上界在数学上仍是一个未解之谜，无法给出确切的渐近表示**。

## 1-9

![image-20260305154715110](./%E7%AC%AC%E4%B8%80%E6%AC%A1%E4%BD%9C%E4%B8%9A.assets/image-20260305154715110.png)

**第1-9题答案:**

设该算法对于规模为 $n$ 的所有输入集合为 $S$。

对于每一个输入 $x \in S$，算法的执行时间记为 $T(x)$。

设平均情况下的时间复杂度为 $T_{avg}(n)$，根据题目已知：$T_{avg}(n) = \theta(f(n))$。

这意味着存在常数 $c > 0$ 和 $n_0$，使得当 $n \ge n_0$ 时，$T_{avg}(n) \ge c \cdot f(n)$

平均时间 $T_{avg}(n)$ 是所有输入执行时间的平均：

$$T_{avg}(n) = \frac{1}{|S|} \sum_{x \in S} T(x)$$

最坏情况下的时间 $T_{max}(n)$ 是所有输入中执行时间的最大值：

$$T_{max}(n) = \max_{x \in S} \{ T(x) \}$$

我们都指导，一组数据的**最大值**必然大于或等于这组数据的**平均值**：

即$$T_{max}(n) \ge T_{avg}(n)$$

代入已知条件可知：

由于 $T_{avg}(n) = \Theta(f(n))$，则必有 $T_{avg}(n) \ge c \cdot f(n)$。

因此：

$$T_{max}(n) \ge T_{avg}(n) \ge c \cdot f(n)$$

因此，如果存在常数 $c$ 和 $n_0$，使得当 $n \ge n_0$ 时，$T(n) \ge c \cdot f(n)$，则 $T(n) = \Omega(f(n))$。

所以，最坏情况下的计算时间为 **$\Omega(f(n))$**。
