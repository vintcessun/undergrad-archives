## 1.1 计算机发展历程

### 1.1.1 计算机的定义

- **计算机**：能够按照事先存储的程序，自动、高速、准确地进行信息处理的电子设备
- 可分为**数字计算机**和**模拟计算机**
- 今天的计算机以**数字计算机**为主

**本节四个方面**：
1. 1.1.1 国外计算机发展概况
2. 1.1.2 摩尔定律
3. 1.1.3 集成电路工艺发展概况
4. 1.1.4 我国计算机发展概况

### 1.1.2 国外计算机发展概况 — 四代机

**世界上第一台电子数字计算机**：
- **ENIAC**（Electronic Numerical Integrator And Computer）
- 1946年2月在美国宾夕法尼亚大学研制成功
- 参数：18000多个电子管，1500多个继电器，耗电150千瓦，重30吨，占地150平方米，运算速度5000次/秒左右
- 意义：科学史上的一次划时代的创新，奠定了电子计算机的基础，宣告人类进入电子计算机时代

> **图片信息**：PPT中有ENIAC的调试照片（第14页图片）。

**四代计算机的发展**：

| 代次 | 时间段 | 核心器件 | 特点 |
|------|--------|---------|------|
| **第一代** | 1946-1958年 | **电子管** | 最早的电信号放大器件，体积大、功耗高 |
| **第二代** | 1958-1964年 | **晶体管** | 固体半导体器件，开关速度快（实验室可达100GHz以上） |
| **第三代** | 1964-1971年 | **集成电路（IC）** | 将晶体管、电阻、电容等元件集成在一小块半导体晶片上 |
| **第四代** | 1971年至今 | **超大规模集成电路（VLSI）** | 将大量晶体管组合到单一芯片，微处理器是其典型实例 |

> **图片信息**：PPT中有电子管、晶体管、集成电路、超大规模集成电路的图片展示（第15页图片）。

> **关联**：四代机的演进体现了电子技术的微型化和集成化趋势，这正是摩尔定律（知识点7）所描述的现象。

### 1.1.3 摩尔定律

**提出者**：戈登·摩尔（Gordon Moore），英特尔公司创始人之一

**提出时间**：1965年，在论文《Cramming More Components Onto Integrated Circuits》中

**摩尔定律原文**：
> 当价格不变时，集成电路上可容纳的晶体管数量大约**18至24个月翻一番**，性能也将提升一倍。

**近年变化**：
- 2013年开始逐步放缓至**3年（36个月）翻一番**
- 半导体工艺已接近集成电路极限

**摩尔定律的意义和影响**（知识点8）：
1. 单个芯片集成度提高后，成本变化不大，总体成本明显下降
2. 电路间距离更近，连线更短，工作速度更高
3. 增加芯片内部连线，减少外部连线，可靠性提高
4. 计算机体积越来越小，减少电能消耗，适应性更好

> **图片信息**：PPT中有摩尔定律的示意图，展示了集成电路上晶体管数量随时间呈指数增长的趋势（第17页图片）。

> **关联**：摩尔定律是集成电路工艺发展（知识点9）的理论指导，也是计算机性能不断提升（知识点41-49）的重要推动力。

---

### 1.1.4 摩尔定律的失效问题与"新摩尔定律"

**经典摩尔定律走到尽头的原因**：

| 因素 | 说明 |
|------|------|
| **物理极限** | 制程工艺推进到3nm甚至2nm时，晶体管尺寸已接近硅原子物理极限，电子可能发生"量子隧穿"效应，导致漏电严重 |
| **成本失控** | 先进晶圆厂（台积电、三星）成本高达数百亿美元，每缩减1nm，研发和制造成本呈指数级上升 |
| **收益骤降** | 从7nm到5nm再到3nm，性能和功耗的改善幅度明显缩小，"每瓦性能"提升放缓 |

**"新摩尔定律"**：依然有效，靠芯粒异构、先进封装、架构革新持续提升算力/能效

---

### 1.1.5 集成电路（IC）生产工艺

IC生产主要分为三大步骤：

| 步骤 | 说明 |
|------|------|
| **IC设计** | 根据芯片设计目的进行逻辑设计和规则制定，制作掩模供后续光刻使用 |
| **IC制造** | 将芯片电路图从掩模转移至晶圆上，包括光刻、刻蚀、离子注入、薄膜沉积、化学机械研磨等 |
| **IC封测** | 对芯片进行封装和性能、功能的测试 |

**IC发展的两个重要标志**：

1. **光刻的最小线条尺寸**（晶体管制程工艺）：
   - 经历了130nm、90nm、65nm、45nm、32nm、28nm、22nm、14nm、10nm、7nm、5nm等阶段
   - 大致按**0.7倍递减**

2. **晶圆的尺寸**：
   - 150mm（6英寸）、200mm（8英寸）、300mm（12英寸）
   - 主流是300mm（12英寸），占所有晶圆的80%左右

> **图片信息**：PPT中有12英寸晶圆的图片及尺寸说明（第20页图片）。

> **关联**：IC生产工艺的进步直接推动了摩尔定律的实现（知识点7），也是计算机四代演进的物理基础（知识点6）。

## 1.2 计算机系统的组成

### 1.2.1 计算机系统的三大组成部分

| 组成部分 | 说明 |
|---------|------|
| **硬件（Hardware）** | 计算机的物理设备 |
| **软件（Software）** | 运行在硬件上的程序和数据 |
| **固件（Firmware）** | 具有软件功能的硬件，是把软件固化在硬件之中的器件 |

**固件示例**：
- 将高级语言的编译程序固化在只读存储器中，该存储器就具有了编译程序的功能
- 计算机主板上的**BIOS**（Basic Input/Output System），通常固化在ROM中，也称为ROM BIOS

---

### 1.2.2 冯·诺依曼体系结构

**提出者**：冯·诺依曼（John von Neumann），美籍匈牙利数学家，被称为"现代计算机之父"

**冯·诺依曼的三个基本原则**：

| 原则 | 说明 |
|------|------|
| **1. 二进制逻辑** | 采用0和1两个状态，更容易用逻辑电路实现（低电平表示0、高电平表示1），适合布尔代数方法实现运算电路 |
| **2. 程序存储执行** | 将程序和数据以二进制形式存放到存储器中 |
| **3. 五大部件组成** | 计算机由运算器、控制器、存储器、输入设备、输出设备五个部分组成 |

**程序控制的含义**：控制器逐条取出存储器中的指令并按顺序执行，控制各功能部件进行相应的操作，完成数据的加工处理。

> **图片信息**：PPT中有冯·诺依曼的照片（第32页图片）。

> **关联**：冯·诺依曼体系结构是现代计算机的基础框架，后续所有知识点（硬件组成、层次结构、性能评价）都建立在这个框架之上。

---

### 1.2.3 冯·诺依曼体系结构图

计算机系统由以下部分组成：

```
        输入设备 ──────→ 输出设备
              ↓              ↑
            存储器 ←────→ CPU
                     ↑        ↑
                   运算器 ← 控制器
```

**主机** = CPU + 存储器（内存）

| 部件 | 功能 |
|------|------|
| **运算器** | 进行算术运算和逻辑运算 |
| **控制器** | 指挥协调各部件工作 |
| **存储器** | 存放程序和数据 |
| **输入设备** | 将外部信息送入计算机 |
| **输出设备** | 将计算机处理结果输出 |

---

### 1.2.4 存储器

**主要功能**：存放程序和数据

**当前计算机的主存储器**：都是**半导体存储器**

**存储器组成框图**：

```
              地址总线
                 ↓
            地址译码
                 ↓
存储体(存储单元0, 1, ..., n) ←→ 数据总线
                 ↑
           读/写控制 ← 读/写命令
```

| 组成部分 | 功能 |
|---------|------|
| **存储体** | 由多个存储单元组成，每个存储单元存放数据 |
| **地址译码** | 将地址信号转换为对应存储单元的选择信号 |
| **读/写控制** | 控制数据的读取和写入操作 |
| **地址总线** | 传输存储单元的地址 |
| **数据总线** | 传输读写的数据 |

> **图片信息**：PPT中有存储器组成框图（第34页图片）。

---

### 1.2.5 运算器

- **功能**：用于信息加工处理的部件，对数据进行**算术运算**和**逻辑运算**
- **组成**：通常由**算术逻辑单元（ALU，Arithmetic and Logic Unit）**和一系列**寄存器**组成

**关键概念 — 机器字长**：
- 运算器一次运算能处理的**二进制位数**
- 现代计算机具有多个寄存器，称为**寄存器组**

> **图片信息**：PPT中有运算器示意图，展示了累加器、寄存器和ALU的连接关系（第35页图片）。

> **关联**：运算器是CPU的核心部件（知识点22），机器字长是重要的性能指标（知识点41）。

---

### 1.2.6 控制器

- **功能**：整个计算机的**指挥中心**，使计算机各部件协调工作
- 计算机中有两股信息在流动：
  - **控制流信息** — 发源地是控制器
  - **数据流信息**

**控制器产生控制流信息的三个依据**：

| 来源 | 功能 |
|------|------|
| **指令寄存器** | 存放当前执行的指令 |
| **状态寄存器** | 存放计算机的当前状态 |
| **时序电路** | 产生时序信号，控制操作的时间顺序 |

> **图片信息**：PPT中有控制器结构图，展示了控制信号产生逻辑、指令寄存器、状态寄存器、时序电路之间的关系（第36页图片）。

> **关联**：控制器与运算器合称为CPU（知识点22），是冯·诺依曼五大部件的核心。

---

### 1.2.7 输入设备和输出设备

**常用输入设备**：
- 键盘、鼠标、扫描仪
- 模/数（A/D）转换器

**常用输出设备**：
- 打印机、显示器
- 数/模（D/A）转换器

**外存储器**：
- 常见：磁盘、光盘、磁带机
- 特点：既可以作为输入设备，也可以作为输出设备
- 也称为辅助存储器，归到存储器设备中

---

### 1.2.8 系统互连 — 总线

- **总线（Bus）**：连接两个或多个设备（部件）的**公共信息通路**
- 总线主要由三部分组成：

| 类型 | 功能 |
|------|------|
| **数据线** | 传输数据 |
| **地址线** | 传输地址 |

## 1.3 计算机系统的层次结构

### 1.3.1 计算机系统的六层层次结构

```
第6层 ┌──────────────┐  高级语言层（C等）          ← 面向用户
      │              │
第5层 │  汇编语言层   │  （MIPS等）                 ← 面向用户
      │              │
第4层 │  操作系统层   │  （资源管理和调度）            ← 面向机器
      │              │
第3层 │ 指令集架构层  │  （ISA层/传统机器层）          ← 软硬件界面
      │              │
第2层 │  微代码层    │  （微程序设计）               ← 硬件
      │              │
第1层 └─硬件逻辑层───┘  （逻辑门、触发器）            ← 硬件
```

**层次划分总结**：
- 第1、2、3层：**硬件层**，是计算机系统的基础和核心
- 第4、5、6层：**软件层**
  - 第4层是**面向机器**的
  - 第5、6层是**面向应用**的

> **图片信息**：PPT中有六层层次结构的示意图（第45-52页图片）。

> **关联**：层次结构与冯·诺依曼体系结构（知识点15）的关系——第3层（ISA层）是冯·诺依曼结构中"程序存储执行"概念的实现层面。

---

### 1.3.2 各层详细说明

**第6层：高级语言层**
- 面向用户的抽象层次
- 用户使用与机器无关的高级语言编程
- 不需要知道机器的技术细节
- 只需掌握高级语言的语法规则、算法和数据结构

**第5层：汇编语言层**
- 为用户提供基于助记符表示的汇编语言编程
- 与机器结构**直接相关**
- 必须了解机器内部的详细技术细节（寄存器、寻址方式）后才能编程

**第4层：操作系统层**
- 对计算机系统的硬件和软件资源进行统一管理和调度
- 提高计算机系统的使用效率
- 方便用户使用计算机

**第3层：指令集架构层（ISA层）**
- 可通过机器语言编写程序实现对计算机硬件的控制
- 也称为传统机器层
- 是计算机中**软件系统和硬件系统之间的界面和纽带**

**第2层：微代码层**
- 实际的机器层
- 用户使用微指令编写微程序
- 微程序由硬件直接执行
- 只有采用微程序设计的计算机才有这一层

**第1层：硬件逻辑层（逻辑门层）**
- 计算机系统最底层的硬件系统
- 由逻辑门、触发器等逻辑电路组成
- 由逻辑设计者采用布尔代数设计的硬件内核

---

### 1.3.3 各层之间的关系

**核心规律**：
> **高层是低层功能的扩展，低层是高层的基础。**

**不同角色看到的计算机**：

| 角色 | 层次视角 | 看到的计算机 |
|------|---------|-------------|
| 程序员 | 第6层 | 处理高级语言的机器 |
| 系统操作员 | 第4层 | 系统的资源 |
| 硬件设计人员 | 第1、2层 | 电子线路和逻辑器件集 |

**动态变化**：
- 机器指令系统级与操作系统级的界面又称为**硬、软件交互界面**
- 随着软件硬化和硬件软化而动态变化
- 操作系统和其他系统软件的界面也有动态变化的趋势

---

### 1.3.4 软件和硬件的逻辑功能等价性

- 计算机硬件实现最基本的**算术运算和逻辑运算**功能
- 其它功能大多通过**软件**的扩充得以实现

**逻辑功能等价性**：
- 部分功能既可以由**硬件**实现，也可以由**软件**实现
- 称为软硬件逻辑功能的等价性

**示例**：浮点数运算
- 可以用专门的**浮点运算器硬件**实现
- 也可以通过**一段子程序**实现

**决定因素**：
- 软件和硬件的功能分配及其界面的确定
- 由设计目标、性能价格比、技术水平等综合因素决定

**趋势**：
- 随着大规模集成电路技术的发展，**软件硬化或固化**是必然趋势
- 例如ROM-BIOS，形式上是硬件，实际内容是软件（固件）

> **关联**：软硬件等价性（知识点27）解释了为什么层次结构中的硬软件界面会动态变化（知识点26）。

---

### 1.3.5 计算机组成与计算机系统结构的区别

| 概念 | 定义 | 关注内容 | 示例 |
|------|------|---------|------|
| **计算机系统结构** | 程序设计者角度看到的计算机系统的属性，即概念性的结构与功能特性 | 指令集、寄存器文件组织、数据表示、存储系统、中断系统、I/O系统、信息保护、工作状态 | 有没有乘法指令（MUL） |
| **计算机组成** | 计算机系统结构的逻辑实现 | 数据通路宽度、专用部件设计、控制机构组成方式、排队与缓冲技术、预估与预判技术、可靠性技术 | 乘法指令实现得快不快 |

**通俗理解**：
- **系统结构**决定"有没有"（功能定义）
- **计算机组成**决定"快不快"（实现方式）

---

### 1.3.6 实例1 — Intel x86架构 vs 不同代CPU

**系统结构（x86架构）** — 对程序员来说都一样：
- 都能运行相同的软件（如Windows 10）
- 都认识相同的机器指令（ADD、MOV等）
- 都有相同的寄存器名（EAX、EBX等）
- 逻辑上看起来都一样

**计算机组成** — 物理上天差地别：

| CPU | 组成特点 |
|-----|---------|
| Core i7-920（2009年） | 原生4核心设计，共享三级缓存，前端总线4.8GT/s |
| Core Ultra 9（2025年） | 大小核混合架构（P-core+E-core），智能缓存层次，支持DDR5，内置NPU |

---

### 1.3.7 实例2 — RISC-V架构

RISC-V是一个**开放的指令集架构**，充分展示了"架构与组成分离"：

**系统结构**：
- 规定了基础整数指令集（如RV32I）
- 规定了加减、跳转指令的二进制编码格式

**计算机组成**（不同实现）：

| 应用场景 | 组成特点 |
|---------|---------|
| 低功耗嵌入式 | 三级流水线（取指、译码、执行），面积小、功耗低，适合物联网设备 |
| 高性能服务器 | 乱序执行、深度流水线、分支预测，组成极其复杂 |

---

### 1.3.8 实例3 — "有没有乘法指令"

**系统结构决定"有没有"**：
- 如果指令集包含MUL指令 → 程序员可以直接写乘法
- 如果指令集没有MUL（为了简化设计）→ 程序员必须用多次ADD和移位运算实现乘法

**计算机组成决定"快不快"**：

| 实现方式 | 速度 | 原理 |
|---------|------|------|
| 低速实现 | 慢 | 使用一个加法器，通过微程序控制，循环累加 |
| 高速实现 | 快 | 使用专门的硬件乘法阵列，实现并行计算 |

> **关联**：这三个实例（知识点29-31）生动展示了系统结构与组成的区别（知识点28），也是后续性能评价（知识点41-49）的理论基础。

## 1.4 计算机性能指标和评价

### 1.4.1 基本性能指标 — 字长

- **字长**：CPU一次处理的数据位数
- 字长一般与计算机内部的寄存器、运算器、数据总线的位宽相等
- 常见分类：16位计算机、32位计算机、64位计算机

**字长对性能的影响**：

| 影响方面 | 说明 |
|---------|------|
| **计算精确度** | 字长越长，计算精确度越高 |
| **定点数表示范围** | 字长越长，表示范围越大 |
| **浮点数表示范围和精度** | 字长越长，范围越大、精度越高 |

---

### 1.4.2 基本性能指标 — 主存容量

- **主存容量**：主存能存储的最大信息量
- 表示方式：M×N
  - M：存储单元数（字容量）
  - N：每个存储单元存储的二进制位数（位容量）
- 示例：8GB内存 = 8×2³⁰×8（M=8×2³⁰，N=8）

**增加主存容量的好处**：
- 减少程序运行期间访问辅存的次数
- 有利于提高程序的执行速度
- 有利于计算机性能的提高

**容量单位换算**：

| 二进制单位 | 值 | 十进制单位 | 值 | 比值 |
|-----------|-----|-----------|-----|------|
| KiB | 2¹⁰ B | KB | 10³ B | 0.97 |
| MiB | 2²⁰ B | MB | 10⁶ B | 0.95 |
| GiB | 2³⁰ B | GB | 10⁹ B | 0.93 |
| TiB | 2⁴⁰ B | TB | 10¹² B | 0.91 |
| PiB | 2⁵⁰ B | PB | 10¹⁵ B | 0.88 |

> **关联**：主存容量是冯·诺依曼结构中"存储器"部件（知识点17）的重要参数。

---

### 1.4.3 与时间有关的性能指标 — 时钟周期

- **时钟周期**：计算机中最基本、最小的时间单位
- 时钟周期是**主频的倒数**，也称为节拍周期或T周期

**示例**：主频 = 1GHz → 时钟周期 = 1ns

---

### 1.4.4 与时间有关的性能指标 — CPI

- **CPI**（Clock Cycles Per Instruction）：执行每条指令所需要的**平均时钟周期数**

**计算公式**：

假设程序中有n类指令：

$$CPI = \sum_{i=1}^{n} (CPI_i \times P_i)$$

其中：
- CPIi：第i类指令的时钟周期数
- Pi：第i类指令的使用频率（或ICi/IC总）

---

### 1.4.5 与时间有关的性能指标 — CPU时间

**CPU时间计算公式**：

$$T_{CPU} = m \times T = \frac{m}{f} = \frac{IC \times CPI}{f}$$

其中：
- m：程序执行所需的时钟周期数
- T：时钟周期
- f：时钟频率（主频）
- IC：程序中包含的总指令条数

**CPU时间与三个因素的关系**：

| 因素 | 符号 | 影响 | 决定因素 |
|------|------|------|---------|
| **时钟频率** | f | 频率越高，速度越快 | CPU的实现技术和工艺 |
| **CPI** | CPI | CPI越小，速度越快 | 计算机的实现技术和指令集结构 |
| **指令条数** | IC | 指令越少，速度越快 | 指令系统的设计和编译技术 |

> **关联**：CPU时间公式是性能评价的核心公式，字长（知识点32）、主存容量（知识点33）、时钟周期（知识点34）、CPI（知识点35）都是这个公式的组成部分或影响因素。

---

### 1.4.6 与时间有关的性能指标 — IPC

- **IPC**（Instructions Per Cycle）：某个时钟周期CPU能执行的指令条数
- IPC是CPI的**倒数**

**重要进展**：
- 随着指令流水线技术和多核技术的发展，IPC的值已经可以**大于1**
- 即1个时钟周期内可以执行1条以上的指令
- 也就是说**CPI也可以小于1**

**影响因素**：
- 指令集体系结构（ISA）
- 处理器微体系结构
- 计算机系统组成
- 操作系统效率
- 应用软件的设计

---

### 1.4.7 与时间有关的性能指标 — MIPS

- **MIPS**（Million Instructions Per Second）：每秒执行百万条指令
- **GIPS**（Giga Instructions Per Second）：每秒执行10亿条指令

**计算公式**：

$$MIPS = \frac{IC}{T_{CPU} \times 10^6}$$

**影响因素**：
- 主频f越高 → MIPS越高
- CPI越小 → MIPS越高

**基准测试程序**：

| 基准程序 | 测试内容 |
|---------|---------|
| **Whetstone** | 测试浮点运算性能 |
| **Dhrystone** | 测试整数编译器及CPU处理整数指令和控制功能的有效性 |

**性能参考数据**（Dhrystone基准测试）：

| 年份 | CPU | 制程 | 主频 | Dhrystone MIPS | IPC |
|------|-----|------|------|----------------|-----|
| 2018 | Intel Core i9-9900K | 14nm | 4.70GHz | 412090 | 87.68 |
| 2020 | AMD Ryzen Threadripper 3990X | 7nm | 4.35GHz | 2356230 | 541.66 |

**注意**：相同基准测试程序，MIPS性能也会不同，因其还会依赖于编程语言。

**Intel Core2 CPU不同语言的Whetstone MIPS对比**：

| 语言 | Basic解释器 | Basic编译器 | FORTRAN | Java | C/C++ |
|------|-----------|-----------|---------|------|-------|
| Whetstone MIPS | 59 | 347 | 347 | 1534 | 2403 |

---

### 1.4.8 与时间有关的性能指标 — MFLOPS

| 单位 | 全称 | 数值 |
|------|------|------|
| **MFLOPS** | Million Floating-point Operations per Second | 每秒10⁶次浮点运算 |
| **GFLOPS** | Giga Floating-point Operations per Second | 每秒10⁹次浮点运算 |
| **TFLOPS** | Tera Floating-point Operations per Second | 每秒10¹²次浮点运算 |
| **PFLOPS** | Peta Floating-point Operations per Second | 每秒10¹⁵次浮点运算 |

**计算公式**：

$$MFLOPS = \frac{IC_{flops}}{T_{CPU} \times 10^6}$$

其中ICflops为TCPU时间内执行的浮点运算次数。

> **关联**：MFLOPS是评价超级计算机性能的主要指标（知识点12"天河二号"和知识点13"神威·太湖之光"的性能就是用FLOPS表示的）。

### 1.4.10 CPU性能公式应用 — 例1.1

**题目**：某程序的目标代码主要由4类指令组成，它们在程序中所占比例和各自CPI如表所示。求：
1. 该程序的CPI
2. 若CPU主频为400MHz，求计算机的MIPS

**解答**：

$$CPI = \sum_{i=1}^{4} (CPI_i \times P_i) = 0.45 \times 1 + 0.32 \times 2 + 0.15 \times 2 + 0.08 \times 2 = 1.55$$

$$MIPS = \frac{f}{CPI \times 10^6} = \frac{400 \times 10^6}{1.55 \times 10^6} = 258$$

> **图片信息**：PPT中有表1.4的截图，展示了4类指令的比例和CPI数据（第68页图片）。

### 1.4.11 CPU性能公式应用 — 例1.2

**题目**：计算机A和B基于相同指令集设计，A的时钟周期为2ns，某程序在A上CPI为3；B的时钟周期为4ns，同一程序在B上CPI为2。问：对该程序，A与B哪个更快？快多少？

**解答**：

$$T_{CPU-A} = 2ns \times 3 \times IC = 6 \times IC \text{ (ns)}$$
$$T_{CPU-B} = 4ns \times 2 \times IC = 8 \times IC \text{ (ns)}$$

$$\frac{T_{CPU-A}}{T_{CPU-B}} = \frac{6}{8} = 0.75$$

**结论**：计算机A比计算机B快，快 **1/0.75 ≈ 1.3333倍**

---

### 1.4.12 CPU性能公式应用 — 例1.3

**题目**：设某计算机中A、B、C三类指令的CPI已知，现有两类不同编译器将同一高级语言语句编译成两种不同代码序列，包含三类指令的数量已知。求：
1. 两种代码序列的CPI分别是多少？
2. 哪种代码的执行速度快？

**核心结论**：

$$CPI_1 = \frac{\sum CPI_i \times IC_i}{IC_{总1}}$$
$$CPI_2 = \frac{\sum CPI_i \times IC_i}{IC_{总2}}$$

**重要发现**：
- 第2种代码的指令数量（6条）比第1种（5条）多
- 但第2种代码的执行速度反而更快
- **原因**：第2种代码中CPI小的指令（A类指令）所占比例更高

> **启示**：程序执行速度不仅取决于指令总数，更取决于指令的CPI分布。这体现了编译优化（选择低CPI指令）的重要性。

> **图片信息**：PPT中有表1.5（三类指令CPI）和表1.6（两种代码序列指令数量）的截图（第70页图片）。

| **显卡测试** | 3DMark、FurMark、GPU-Z、Fraps、SiSoftware Sandra |
| **CPU测试** | CPU-Z、SiSoftware Sandra、Geekbench、Fritz、Super PI |
| **内存测试** | SiSoftware Sandra、MemTest、PassMark Performance Test |
| **综合性测试** | SiSoftware Sandra、鲁大师、安兔兔 |

**基准测试程序（Benchmark）**：
- 将应用程序中使用频率最高的核心程序作为评价计算机性能的标准程序
- 流行基准程序：Dhrystone、Whetstone、Linpack、SPEC、NPB等

## 1.5 课程学习的建议

### 1.5.1 课程学习建议 — 三观

**通过本课程学习，应达到的目标**：
- 理解计算机核心组成部件（运算器、控制器、存储器等）的内部结构、工作原理、设计与实现方法

| **3. 工程观** | 软硬件协同视角下的计算机系统开发和实现能力 | 考虑工程制约因素，选择恰当技术和工具进行工程优化 |
