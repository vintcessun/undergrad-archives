## 三、实验总结与心得记录

在本次实验中，我完成了 Java SE $21/25$ 环境的安装 、IntelliJ IDEA 的配置 以及基础 I/O 程序的编写 。以下是实验过程中的详细记录与体会：

**1. 解决多版本 Java 冲突**

- **遇到的问题**：由于电脑中预存有旧版的 **Java 8**，在安装完 JDK 21 后，通过命令行执行 `javac --version` 依然显示为旧版本 。
- **解决方法**：我检查了系统环境变量，发现 Path 路径中旧版的 `javapath` 优先级高于新安装的 JDK 21。
- **心得**：通过手动调整环境变量的顺序，并删除了一些自动生成的无效路径，最终成功切换到了目标版本 。这让我意识到环境配置不仅仅是安装软件，更涉及到操作系统对程序调用路径的管理。

**2.实验题目实现过程的心得** 

- **输入输出方式对比**：我测试了 `Scanner` 类进行标准输入输出 。
- **代码逻辑**：在 IDEA 中编写代码时，我发现 Java 的类名（如 `Main`）必须与文件名严格对应 。通过 `System.out.println` 进行输出时，这种链式调用虽然初看比 C 语言繁琐，但逻辑非常清晰 。
- **细节注意**：在处理输入时，我注意到 `nextLine()` 方法在连续读取时有时会受到换行符的影响 ，这要求我们在编写逻辑时必须考虑缓冲区的情况。

**3. 对 Java 语言的初步认识**

- **工程化思维**：相比于简单的文本编辑器，使用 IDEA 极大地提高了效率 。其自动补全和实时错误检测功能，对于初学者理解 Java 复杂的语法结构非常有帮助。
- **严谨性**：Java 强类型的特性要求每一个变量（如 `String name`）都必须明确定义 ，这种严谨性虽然增加了代码量，但大大减少了运行时出错的概率。

**4. 总结** 本次实验让我从底层的 JDK 环境配置到上层的 IDE 应用有了完整的体验 。特别是解决 Java 8 冲突的过程，加深了我对 JRE和JDK之间关系的理解。
