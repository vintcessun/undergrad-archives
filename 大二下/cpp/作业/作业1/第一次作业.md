### 2.7 第7题

![image-20260401111856347](./%E7%AC%AC%E4%B8%80%E6%AC%A1%E4%BD%9C%E4%B8%9A.assets/image-20260401111856347.png)

#### (1) `x + 3/y - 2 * z`

- **计算步骤：**
  1. 处理除法：`3 / y` 即 `3 / 2`。由于是 `int` 型运算，结果为 **1**（舍去小数）。
  2. 处理乘法：`2 * z` 即 `2 * 3`，结果为 **6**。
  3. 执行加减：`x + 1 - 6` 即 `1 + 1 - 6`。
- **计算结果：** **-4**

#### (2) `x > 0 || y < 2 && z > 1`

- **计算步骤：**
  1. 根据优先级，先计算关系运算符：
     - `x > 0` 为 **true** (1)
     - `y < 2` 为 **false** (0)
     - `z > 1` 为 **true** (1)
  2. 处理逻辑运算符（优先级 `&&` 高于 `||`）：
     - `y < 2 && z > 1` 为 `false && true`，结果为 **false** (0)。
  3. 最后计算 `||`：
     - `x > 0 || false` 即 `true || false`。
- **短路求值说明：** 在实际运行中，由于 `x > 0` 已为 **true**，逻辑或 `||` 会发生短路，不再计算右侧表达式。
- **计算结果：1**

#### (3) `z > y > x`

- **计算步骤：**
  1. 关系运算符具有左结合性，先计算左侧：`z > y` 即 `3 > 2`，结果为 **true** (在 C++ 表达式评估中返回数值 **1**)。
  2. 再计算剩余部分：`1 > x` 即 `1 > 1`。
- **注意点：** 这是一个典型的逻辑陷阱，该表达式并非判断 `y` 是否在 `x` 和 `z` 之间，而是将前者的布尔结果与后者进行数值比较。
- **计算结果：0**

### 2.7 第8题

![image-20260401112409587](./%E7%AC%AC%E4%B8%80%E6%AC%A1%E4%BD%9C%E4%B8%9A.assets/image-20260401112409587.png)

#### (1) `3/5 * 12.3`

- **转换过程：**
  1. 首先计算 `3/5`：由于 `3` 和 `5` 都是 `int` 型，执行整数除法。**结果为 0**（`int` 型）。
  2. 接着计算 `0 * 12.3`：`0` 是 `int` 型，`12.3` 是 `double` 型。根据规则，`int` 转换为 `double`。
  3. 最终运算：`0.0 * 12.3`。
- **计算结果：** **0.0**

#### (2) `'a' + 10 * 5.2`

- **转换过程：**
  1. 处理乘法 `10 * 5.2`：`10` 是 `int` 型，`5.2` 是 `double` 型。`int` 转换为 `double`，计算结果为 **52.0**（`double` 型）。
  2. 处理加法 `'a' + 52.0`：`'a'` 是 `char` 型（ASCII 值为 97），`52.0` 是 `double` 型。`char` 首先提升为 `int`，再提升为 `double`。
  3. 最终运算：`97.0 + 52.0`。
- **计算结果：** **149.0**

#### (3) `12U + 3.0F * 24L`

- **转换过程：**
  1. 处理乘法 `3.0F * 24L`：`3.0F` 是 `float` 型，`24L` 是 `long` 型。`long` 转换为 `float`。计算结果为 **72.0**（`float` 型）。
  2. 处理加法 `12U + 72.0F`：`12U` 是 `unsigned int` 型，`72.0F` 是 `float` 型。`unsigned int` 转换为 `float`。
  3. 最终运算：`12.0F + 72.0F`。
- **计算结果：** **84.0**

int main() {
    double pi_over_4 = 0.0;
    double term = 1.0;     // 当前项的值
    double denominator = 1.0; // 分母
    int sign = 1;          // 符号位，正负交替

    // 循环直到当前项的绝对值小于 10^-8
    while (fabs(term) >= 1e-8) {
        term = sign * (1.0 / denominator);
        pi_over_4 += term;
        
        // 更新下一项的参数
        denominator += 2.0;
        sign = -sign;
    }

    double pi = pi_over_4 * 4.0;

    cout << "计算得到的圆周率 pi = " << fixed << setprecision(8) << pi << endl;

}

#### 1.代码

```c++
#include <iostream>

using namespace std;

// Ackermann 递归函数
int ack(int m, int n) {
    if (m == 0) {
        return n + 1;
    } else if (n == 0) {
        return ack(m - 1, 1);
    } else {
        return ack(m - 1, ack(m, n - 1));
    }
}

int main() {
    int m = 2, n = 2;
    cout << "ack(" << m << ", " << n << ") = " << ack(m, n) << endl;
    return 0;
}
```

#### 2.$ack(2, 2)$ 的手工推导过程

为了计算 $ack(2, 2)$，我们需要按照递归定义逐步展开：

- $ack(2, 2) = ack(1, ack(2, 1))$
  - 先计算 $ack(2, 1) = ack(1, ack(2, 0))$
  - 再计算 $ack(2, 0) = ack(1, 1)$
    - $ack(1, 1) = ack(0, ack(1, 0))$
    - $ack(1, 0) = ack(0, 1) = 1 + 1 = 2$
    - 由此得 $ack(1, 1) = ack(0, 2) = 2 + 1 = 3$
  - 回代得 $ack(2, 1) = ack(1, 3)$
    - $ack(1, 3) = ack(0, ack(1, 2))$
    - $ack(1, 2) = ack(0, ack(1, 1)) = ack(0, 3) = 4$
    - 由此得 $ack(1, 3) = ack(0, 4) = 5$
- 回代最终式：$ack(2, 2) = ack(1, 5)$
  - $ack(1, 5) = ack(0, ack(1, 4))$
  - $ack(1, 4) = ack(0, ack(1, 3)) = ack(0, 5) = 6$
  - 由此得 $ack(1, 5) = ack(0, 6) = 7$

**计算结果：**

**$ack(2, 2) = 7$**

#### 1.代码

```c++
#include <iostream>

using namespace std;

void reverse(int a[], int left, int right) {
    while (left < right) {
        int temp = a[left];
        a[left] = a[right];
        a[right] = temp;
        left++;
        right--;
    }
}


void swap(int a[], int m, int n) {
    reverse(a, 0, m - 1);
    
    reverse(a, m, m + n - 1);
    
    reverse(a, 0, m + n - 1);
}

int main() {
    int m = 3, n = 4;
    int a[] = {1, 2, 3, 4, 5, 6, 7}; // 前3个: {1,2,3}, 后4个: {4,5,6,7}

    swap(a, m, n);

    // 输出验证结果
    for (int i = 0; i < m + n; i++) {
        cout << a[i] << " ";
    }
    // 预期输出: 4 5 6 7 1 2 3
    return 0;
}
```

#### 1.代码

```c++
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <iomanip>

using namespace std;

// 定义学生信息结构体
struct Student {
    string id;              // 学号
    string name;            // 姓名
    double scores[8];       // 8门课成绩
    double average;         // 平均分

    // 计算平均分的成员函数
    void calculateAverage() {
        double sum = 0;
        for (int i = 0; i < 8; ++i) {
            sum += scores[i];
        }
        average = sum / 8.0;
    }
};

// 比较函数：用于 sort 降序排列
bool compareStudents(const Student& a, const Student& b) {
    return a.average > b.average; 
}

int main() {
    int n;
    cout << "请输入学生人数: ";
    cin >> n;

    vector<Student> students(n);

    // 输入信息
    for (int i = 0; i < n; ++i) {
        cout << "正在输入第 " << i + 1 << " 个学生的信息：" << endl;
        cout << "学号: "; cin >> students[i].id;
        cout << "姓名: "; cin >> students[i].name;
        cout << "请输入8门课的成绩: ";
        for (int j = 0; j < 8; ++j) {
            cin >> students[i].scores[j];
        }
        students[i].calculateAverage(); // 计算平均分
    }

    // 按照平均成绩由高到低排序
    sort(students.begin(), students.end(), compareStudents);

    // 输出结果
    cout << "\n--- 学生成绩排名表 (按平均分降序) ---\n";
    cout << left << setw(15) << "学号" << setw(10) << "姓名";
    for (int j = 1; j <= 8; ++j) cout << "课" << j << "  ";
    cout << "平均分" << endl;

    for (const auto& s : students) {
        cout << left << setw(15) << s.id << setw(10) << s.name;
        for (int j = 0; j < 8; ++j) {
            cout << fixed << setprecision(1) << s.scores[j] << " ";
        }
        cout << " [" << s.average << "]" << endl;
    }

    return 0;
}
```
